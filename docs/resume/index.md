**January 2022 – August 2026.** Founded and led the AI and Data Science R&D
division, for telecommunications and network optimization.

Missions:

- Built the research unit from scratch: research priorities, methodology, and
  collaboration between IT developers and network engineers.
- Applied machine learning and deep learning to mobile network performance,
  reducing inefficiencies and enabling predictive maintenance.
- Designed validation and monitoring frameworks so AI solutions were safe,
  reliable and production-ready.
- Mentored an intern and an MSc apprentice (M2), aligning their research with
  both industrial and pedagogic goals.

Projects:

- Internal RAG based on a Large Language Model and a Knowledge Graph, for
  knowledge management and operational support.
- Time series forecasting for anomaly detection and network demand prediction.
- Network Intelligence on cloud services: data science use cases implemented on

  prediction.
- Multi-class classification for automatic labelling.
- Historical data analysis for energy saving.

Technical stack: Python (NumPy, Pandas, Polars, Scikit-Learn, TensorFlow,
Keras), SQL, Superset, Airflow, Cypher.
